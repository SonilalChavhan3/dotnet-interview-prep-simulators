 ASP.NET Core MVC State Management Simulator
What It Is
A single-file interactive HTML learning tool for ASP.NET Core MVC state management. No install, no backend, no dependencies — just open index.html in any browser.

How to Use
Save the file as index.html

Double-click to open in Chrome / Edge / Firefox / Safari

Use the left sidebar to navigate sections

Interactive Simulator — pick any of 14 state techniques and see where data lives, with step-by-step flow

Request Lifecycle — clickable stages from Browser → Response

Multi-Server Comparison — single vs. distributed architecture

Security Matrix — what users can inspect, modify, or trust

Comparison Table — searchable, with all techniques

45+ Interview Questions — Beginner / Intermediate / Advanced

 ASP.NET Core MVC State Management Simulator
A single-file, interactive HTML learning tool for mastering state management in ASP.NET Core MVC.
No install. No backend. No dependencies. Just open and learn. 🚀

🎯 What Is This?
An interactive simulator that visually teaches how state is stored, transferred, and secured in an ASP.NET Core MVC application — from beginner concepts to advanced interview-level topics.

Built for:

🧑‍🎓 Beginners learning ASP.NET Core MVC

💼 Developers preparing for .NET interviews

👨‍🏫 Trainers teaching state management

📖 Anyone needing a quick visual reference

🚀 How to Use
1️⃣ Save the file
Download or copy the code into a file named index.html.

2️⃣ Open it
Double-click index.html → opens in your default browser.

✅ Works with Chrome, Edge, Firefox, Safari
✅ No server, no Node.js, no build step, no internet needed

3️⃣ Explore
Use the sticky sidebar to jump between sections. Everything is clickable.
